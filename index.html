Frequently asked questions

Quick answers about the Sodor Trainer ESP.

Is the trainer free to use?
Yes. sodor-trainer-esp is completely free and open source. You can download the latest build, inspect the source, and even compile it yourself from the repository.
Which game versions are supported?
The trainer targets the current Steam release of Thomas & Friends: Wonders of Sodor on Windows 10 and Windows 11. After major game patches, an updated build is usually published within a few days.
Will the speed hack or wallhack break my save?
No. All modules work in memory only and never modify your save files. Unlocking routes simply flags them as available for the current session, and toggles reset when you close the game.
Do I need to disable my antivirus?
Some antivirus engines flag memory-reading trainers as potentially unwanted. Since the project is fully open source, you can verify the code yourself or build from source. Add an exclusion for the folder if needed.
